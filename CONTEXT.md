# Jobs App domain language

- **Jobs App** — the independent plugin `@dshapps/jobs-app`, App ID `dshapps.jobs`.
- **Glance list** — the official session-header popover from `@deepseek-ai/dsh-client-ui-jobs`. Not this package.
- **Deep-link** — `ctx.pages.open('dshapps.jobs', path)` from the Jobs App header action.
- **Job view** — the `jobsBySession` mirror (`id`, `kind`, `label`, `status`, `detail`, `startedAt`, `finishedAt`).
